# Arquitectura de la Aplicacion:

## Arquitectura

El proyecto sigue una arquitectura MVC:

* Models: acceso a datos.
* Views: interfaz gráfica.
* Controllers: lógica de aplicación.


## Tecnologías

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* PHP 8.2 (sin framework)
* MySQL 8
* Apache
* Composer
* PHPUnit

## Requisitos

* PHP >= 8.2
* Composer >= 2.8
* MySQL >= 8.0
* Apache 2.4
