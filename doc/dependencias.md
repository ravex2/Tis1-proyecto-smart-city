## PHP:
PHP version ">= 8.5.0".

## Estructura de proyecto:
config: archivos de configuracion de dependencias, database.
controllers: controladores
core: configuracion nucleo (lo mas importante)
views: paginas. y layout

## Dependencias:
uso de composer:
* twig: gestion de plantillas en php para la implementacion
* phpdotenv: variables de configuracion
* (ideal) implementacion ORM illuminate/database: Es el ORM (Eloquent), para no escribir SQL manual
* respect/validation: validacion de formularios
* logs: monolog/monolog, podria ser otro pero es una buena
